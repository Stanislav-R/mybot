# Telegram Bot (Go + Telebot)

A lightweight Telegram bot written in Go using the [Telebot v4](https://github.com/tucnak/telebot) framework.

---

## 📋 Features

- Handles basic commands (e.g., `/hello`).
- Configured via environment variables for easy deployment.
- High-performance, concurrent message handling powered by Go.

---

## 🛠️ Prerequisites

- **Go** (v1.20 or later recommended)
- **Telegram Bot Token** (Obtained from [@BotFather](https://t.me/BotFather))
